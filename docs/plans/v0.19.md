# Release 0.19.0

The checklist for 0.19.0: what the release contains, what the docs already
say, and the steps left before and after publishing. This file does not
publish anything.

[#96](https://github.com/kameka22/snap-studio/pull/96) sets the app version
to **0.19.0** (`src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, the
`snap-studio` package of `src-tauri/Cargo.lock`), turns the changelog's
Unreleased into `## [0.19.0] — 2026-11-08`, and makes What's new `current`
**0.19**, with Snappy first. The latest published tag is still `v0.18.0`.

## Publishing, in order

1. **The release date is 2026-11-08**, in `CHANGELOG.md` (the section's
   title), `site/whats-new/versions.json` (`date` of 0.19) and
   `docs/technical-overview.md` (the development log). If the release slips,
   change all three: `scripts/release.sh` keeps a version section already
   written, date included.
2. Approve and pass the CI run of #96 (a pull request from a fork waits for
   a maintainer before its tests run).
3. Merge #96 **right before** step 4: `pages.yml` publishes the site, the
   0.19 What's new page included, on every push to `main`.
4. `scripts/release.sh` on an up-to-date `main`: 0.19.0 is not published
   yet, so it is reused without a bump. It pushes and starts `build.yml`;
   it has no dry run.
5. After the build: the release files (`latest.json`, AppImage and deb for
   amd64 and arm64, the macOS universal `.app.tar.gz` and `.dmg`, the
   Windows `x64-setup.exe`, prefix `Snap-Studio_0.19.0`), their signatures,
   an update from 0.18.0, a fresh install.

## Checks still open

Manual, not run by CI:

- Snappy (#95): turn on and off, the introduction on a fresh and on an
  existing install, the switch locked without the AI, the card beside the
  slice sheet and above an Explore site, allow / refuse / dismiss, memory
  controls. Real Claude runs (`CHAT_REAL`, `AUTH_REAL`, `IA_REAL`) and the
  container mode are opt-in; Linux CI is not macOS, WebKit or Windows.
- #89: an in-app slice of a T or a bridge (badge, overhangs, warning,
  slice again).
- #88: macOS and Windows.
- #16: plate kept per printer, spool-change warning, suggested temperature,
  start mismatch, glue reminder, on the simulator `farm`. Graphic Effect is
  the least sure pair.
- #90: the release maintainer confirms that the `APTABASE_APP_KEY` secret is
  configured (never read or shown). Without it the count is off, by design.
