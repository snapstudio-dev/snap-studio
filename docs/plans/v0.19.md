# Release 0.19.0 — documentation draft

Preparation only. This file is the checklist for the release notes, What's
new, screenshots and the version switch. It does not publish a release, and
it does not implement a feature.

Refreshed 2026-11-07 against upstream `main` at
`23d02a40de186db1b0a7d2754b93190e1bb78e98` (the anonymous-usage commit,
[#90](https://github.com/kameka22/snap-studio/pull/90)). The app version in
`src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml` and
`src-tauri/Cargo.lock` is still **0.18.0**. Latest tag: `v0.18.0`. No 0.19
release, tag or earlier release-preparation pull request.

Follows the documentation shape of
[#85](https://github.com/kameka22/snap-studio/pull/85) (branch `docs/v0.18`).
`scripts/release.sh` commits, pushes and starts `build.yml`. It is not a
dry run and must not be used for this draft. `scripts/engine.sh` and a
manual run of `build.yml` publish as well. Do not dispatch them.

When #95 is merged, continue below: date Unreleased only with a chosen
release date, set the three version files to 0.19.0 (the package entry of
